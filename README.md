# 💎 Finanças Pro

Controle financeiro completo em uma única página: dashboard mensal, entradas e saídas,
categorias, sites/sistemas vendidos, metas de economia, anotações e personalização
(cores, imagem de fundo e partículas).

Os dados ficam salvos no navegador (localStorage), sem servidor.

## Rodar localmente
```bash
npm run dev
```

## Publicar na Vercel
**Pelo painel:** vercel.com/new → importe o repositório do GitHub → Deploy.
**Pelo terminal:**
```bash
npm run deploy
```
